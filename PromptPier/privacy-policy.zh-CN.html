PromptPier

隐私政策

本隐私政策说明 PromptPier 在您使用 Chrome 扩展及相关云端同步服务时，如何收集、使用、存储和保护您的信息。

最后更新：2026 年 4 月 16 日
联系邮箱： develop@hosemi.cn
English version · 全部法律文档

1. 我们是谁

PromptPier 是一款浏览器扩展及相关服务，帮助您保存、整理、同步 AI 提示词，并在 ChatGPT、DeepSeek 等支持的网站中一键插入。

2. 我们收集的信息

根据您的使用情况，我们可能处理以下信息：

  • Google 账号信息 — 当您使用 Google 登录时，我们会获取您授权范围内的基本资料（如邮箱、昵称、头像），用于识别您的账号。
  • 您创建的提示词内容 — 标题、正文、标签、颜色标记、收藏状态及时间戳。
  • 同步元数据 — 用于多端保持数据一致的版本号与变更记录。
  • 扩展本地数据 — 会话令牌、缓存的提示词列表、站点适配器配置、语言偏好等，保存在浏览器中。

我们不会要求您设置独立密码，也不会读取第三方 AI 网站的完整聊天记录。扩展仅在您主动插入提示词或使用页面内 ~ 选择器时，与输入框进行交互。

3. 信息的使用方式

我们使用上述信息用于：

  • 验证身份并将数据与您的账号关联；
  • 在扩展与 Web 端之间存储和同步提示词；
  • 按您的操作将选定文本插入支持的页面；
  • 提供搜索、筛选与分类功能；
  • 维护服务安全并排查故障。

我们不会出售您的个人信息。

4. 数据存储位置

  • 云端 — 账号元数据与已同步的提示词存储在 PromptPier 使用的 Cloudflare Workers KV 基础设施中。
  • 您的浏览器 — 扩展通过 Chrome 存储 API 在本地保存会话与缓存数据。

离线时，扩展可能继续显示本地缓存；网络恢复后会尝试同步。

5. 权限与页面行为

扩展可能申请以下权限：

  • identity — Google 登录；
  • storage — 本地保存提示词与设置；
  • activeTab — 在您插入提示词时与当前标签页交互；
  • clipboardWrite — 在无法注入页面时复制到剪贴板；
  • sidePanel — 显示侧栏管理界面；
  • 主机访问权限 — 连接 PromptPier API，并在您访问的网页上运行内容脚本。

内容脚本仅用于识别支持的聊天输入框、显示可选的 ~ 提示词选择器，以及插入您选择的内容，不会用于采集无关页面内容。

6. 第三方服务

PromptPier 依赖的第三方服务包括：

  • Google — OAuth 登录与账号验证；
  • Cloudflare — API 托管与提示词存储。

您使用 Google 登录时，亦受 Google 隐私政策 约束。

7. 数据保留与删除

在您的账号处于活跃状态期间，我们会保留账号数据与提示词以提供服务。删除的提示词在同步数据中采用软删除方式处理，备份中可能短期保留。

如需申请删除账号或数据，请发送邮件至 develop@hosemi.cn。您也可通过卸载扩展并清除浏览器扩展存储来移除本地数据。

8. 安全

我们通过 HTTPS 传输 API 数据，并在 Google 登录后签发访问令牌。尽管无法保证绝对安全，我们会采取合理措施保护您的信息。

9. 儿童隐私

PromptPier 不面向适用法律所规定年龄以下的儿童。如您认为儿童通过本服务提供了个人信息，请联系我们，我们将采取适当措施。

10. 政策变更

我们可能不时更新本政策，顶部「最后更新」日期将反映最新版本。变更生效后继续使用 PromptPier，即表示您接受更新后的政策。

11. 联系我们

如有隐私相关问题或请求，请发送邮件至 develop@hosemi.cn。

本页面作为 PromptPier 在 Chrome 应用商店及产品内法律链接的公开隐私政策地址使用。
